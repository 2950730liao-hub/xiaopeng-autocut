# 同系列竖版封面、标题和简介

精剪后依据最终保留的台词、可核实的实例和目标观众，逐条生成一张封面、一条标题、一段简介。已有视频补文案时用当前选定版本。看完同批视频的主线再做标题，避免几个主题写成同一个问题。

## 封面

- 同一垂直主题共用系列名、字体、色彩、标题位置与人物构图。默认竖版 9:16，1080×1920 JPEG。每条从原片或无字粗剪挑一帧，优先眼睛张开、面部清楚、人物与标题有留白。记录取帧素材和时间码。
- 封面文字最多两行。第一行让人快速认出主题，第二行给问题、结果或动作。用缩小预览核对字是否清楚，检查常见的居中 4:5、1:1 缩略裁切是否还能读到核心标题。裁切只是预检，平台样式有明确要求时按指定平台尺寸验。
- 复用 [Remotion 竖版封面](../assets/vertical-cover.tsx)。把该文件复制到能解析 Remotion 和 React 的现有本地工程，人物帧和已授权字体放在其 public 目录。每条准备一个输入 JSON，包含 portrait、fontFile、series 和两条 lines。路径使用 public 下的相对路径。

```sh
npx remotion still vertical-cover.tsx VerticalCover cover.jpg --props=cover.json --image-format=jpeg
```

## 标题与简介提示词

> 读这条成片实际保留的台词。找出观众最想解决的一个问题，用自然口语写一条能独立读懂的标题；把关键词放前面，交代观众会看到的观点或做法。封面文字比标题短。简介用两三句讲清楚场景、成片里真的讲到的一个方法或案例，以及观众能带走什么。参考说话人的语气；只在最终口播确有个人经历时使用第一人称。若台词的数字是举例，文案也表达为举例。避免暗示未展示的教程、业绩、效果承诺或发布表现。

## 交付和验收

逐条交付 JPEG，以及包含 id、cover、portraitSource、lines、title、description 的 JSON。需要复制发布时再附同内容的可读文案。核对封面和文案能否匹配到正确视频，核对版面安全区、文字溢出、人物遮挡、错别字、字幕证据和素材来源。统一写入待审状态；用户授权之前保留本地。
