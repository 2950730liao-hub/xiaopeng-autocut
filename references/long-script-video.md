# 长稿直接出横屏成片

用户贴长稿、讲课稿、访谈转写或文章时，按已设默认进入本流程；仅要求文字结果时按其明确要求处理。按稿件和任务直接做完，交付精简稿、横屏 MP4 和可回看时间线。

1. **梳理精简。** 提取一个主问题、原作者的结论和解释该结论所需的证据。去口头重复、寒暄和不服务本片的导流。用短句保留原意、关键条件、例外和出处。对转写错字、术语、时效性或影响结论的数字核对原始资料或官方来源。未核实又不影响主线的宣传数字可省略。示例加上「教学示例」标识，不替作者编造经历、测试结果或承诺。未指定时长时，短讲可先按约 60–90 秒组织；内容所需时长优先。口播定稿每个非空行对应一段。
2. **按语义设计画面。** 首屏给出观众要解决的具体问题，并在前几秒安排一次有意义的状态变化。按台词决定对象、动作、依据和结果，能贯穿时用同一个例子保持因果。关键动词给可见过程，具体名词用相关图像或文档，数字只做有依据的信息卡。每拍只有一个主焦点。按[语义开场与关键动作](video-modes.md#语义开场与关键动作)设计适合本稿的 HyperFrames 场景。
3. **生成本地旁白并对齐。** 优先沿用用户已配置且批准的本地克隆音色。模板默认后期保音高 1.15 倍，用户指定语速时使用指定值。以下入口每支片只加载一次音色模型与说话人嵌入，再逐段强制对齐。发现关键术语听感异常，优先改成可读的中文语序或按段修正，画面保留正式名称。使用实际新音频时间码，避免沿用上一条视频的帧数和时长。

   ```sh
   voice_home="${XIAOPENG_LOCAL_VOICE_HOME:-$HOME/Applications/Qwen3-TTS-Local}"
   "$voice_home/.venv/bin/python" "$SKILL/local/prepare-local-narration.py" \
     精简定稿.txt "$OUT/音频" --tempo 1.15
   ```

   入口使用该机已有的 Qwen3-TTS 本地默认音色与 MLX 强制对齐器。通过 `XIAOPENG_LOCAL_VOICE_HOME` 和 `XIAOPENG_LOCAL_ALIGNER` 指向已配置的本地目录。保留音色参考资料在本机。首次配置或迁移看[新 Mac 安装与本地音色配置](install-on-new-mac.md)。环境缺失时说明具体原因，并继续完成精简稿和可独立制作的视觉内容。
4. **制作并合成。** 用 `时间线.json` 的段落起止帧及 token 时刻安排镜头与事件音。画面默认 1280×720、30 fps，主画面和证据高于底部字幕区。进行简单配乐与音效时，优先使用已授权素材，配乐给旁白让位，音效在关键动作落稳时触发。输出和旁白同帧数的无字幕画面与终混 WAV，再用 Remotion 固定下栏的逐词高亮。字幕从 `字幕页.json` 读取，按[字幕状态去重](video-modes.md#换旁白与-remotion-字幕提速)合成，跨片复用渲染包。

   ```sh
   node "$SKILL/local/caption-overlay.mjs" --warmup
   node "$SKILL/local/caption-overlay.mjs" "$OUT/音频/字幕页.json" "$FRAMES" \
     "$OUT/无字幕画面.mp4" "$OUT/终混.wav" "$OUT/成片.mp4" "$OUT/字幕耗时.json"
   ```

   `FRAMES` 取自本片 `时间线.json` 的 `frames`。本机 Remotion 依赖通过 `XIAOPENG_REMOTION_MODULES` 指向已准备的依赖目录。横屏以外的画幅走对应字幕 composition。
5. **核验与交付。** 查视频尺寸、帧数、音画长度与完整解码。抽看首个动作、主要证据和结尾，检查实际字幕排版与词高亮。用本机听感或独立转写检查关键人名、术语和数字。通过后直接给成片以及定稿，制作文件中保留时间线和耗时。多个稿件按各自语义独立分镜，复用已安装的本地模型和字幕渲染包，分别记录阶段及批次耗时。

验收示例为「项目延期，AI 怎么查？」。它从周报与群聊的两种说法开场，展示片段检索，再将周报与会议纪要整理成有出处的项目词条。这是编排方式示例。新稿以本稿的主题、素材和因果设计镜头。
