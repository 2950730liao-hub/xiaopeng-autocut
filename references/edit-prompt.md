# Remotion 口播精剪提示词

把以下提示交给能读取素材并运行 Remotion 的 Codex。每条视频独立填写观众、观点和证据。

## 可复制提示词

你负责把素材剪成一条中文短视频。先用一句话写清楚谁会看、为什么愿意看、最后带走什么。沿用说话人的观点和口气。常规版保留说话顺序、完整论点、例子和收尾，先用字幕、景别和素材改善观感。只有用户指定短版或删段有明确理由时，才压缩完整句。保留影响语义的停顿、限定条件和前后逻辑。

输入包括观众、目标、原片或粗剪、逐句时间码、原片映射、干净人声、可用素材及范围、剪映参考与上一版、尺寸帧率、是否配乐。

使用 Web 粗剪交接时，以粗剪视频和已处理人声为共同输入，字幕使用交接的粗剪输出时间。保留气口处理结果。若只拿到原片，先按粗剪交接流程取得版本和处理回执，再开始编排。

- 前几秒选本人实录里有冲突、结果或反差的一句。首屏标题补足语境，回读开头和后一句，保证代词有指向。保留原句出处。
- 按「问题 → 证据或方法 → 结论」检查每一段。已在粗剪处理过的重录无需重复裁剪。先列出有意去掉的完整台词及理由，再确认原始论点有无损失；紧凑版另存。
- 画面有任务时再切。重要名词用可辨认的图像，动词优先给真实操作或动作动画，数字给数量、大小或前后对照。每个信息点只选一种主要表现，跟实际触发帧。优先用本人原片、真实操作记录和可追溯本地素材，再用实际数据绘制解释图。示意明确标注，证据不足时保留口播。
- 从剪映参考提取字幕层级、切换节奏和声音关系。逐条选择标题、字体、动效及密度。字幕避开嘴部和操作区，按词边界换行，校对口播原文。
- 人声清楚优先。音效用于大字落点、操作切换、数字变化或结论，单独列音效轨和相对人声音量。要求无配乐时只用干净人声和短音效。
- 先输出结构化计划，再运行 Remotion。

| 字段 | 内容 |
|---|---|
| audience、takeaway、hook | 受众、带走的一句话、开场原话 |
| sourceClock、fps、clips | 时间钟、帧率、保留段的 id、start、end 和 reason，按输出顺序排列 |
| cues | clip、at、end、kind、quote、title 及音效参数，时间使用源时间 |
| sourceEvidence、sound | 素材证据及其出处、是否实证或示意、是否配乐 |
| review | 易误读的词以及需要优先验收的时间点 |

渲染前把台词、事件与音效从源时间映射到同一输出帧时钟。区间不能越界；口播段不能无意重复；字幕不能跨已删除的内容。以静音画面、纯听声音、完整播放三遍检查，并报告实际检查和未验证项。不估算平台播放量。
